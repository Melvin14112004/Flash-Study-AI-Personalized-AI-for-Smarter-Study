## Title of the Project

Flash Study AI is an AI-powered learning assistant that transforms academic PDF documents into structured and interactive study resources such as summaries, flashcards, quizzes, mind maps, and semantic search results. The system utilizes advanced Natural Language Processing (NLP) and transformer-based deep learning models to improve learning efficiency and reduce the time required for manual studying.

## About

The **Flash Study AI** project is designed to help students study smarter and faster by automating the extraction and organization of important information from academic materials. The system processes uploaded PDF documents and generates concise summaries, intelligent flashcards, quizzes, semantic search capabilities, and visual mind maps.

The project integrates transformer-based NLP models with a modern full-stack architecture to provide an interactive and personalized learning environment. Flash Study AI aims to reduce cognitive overload and improve knowledge retention for students preparing for examinations or revising large volumes of study material.

## Features

- Upload and process academic PDF documents.  
- AI-generated document summarization using transformer models.  
- Automatic flashcard generation for active recall learning.  
- Quiz generation based on document content.  
- Mind map generation for conceptual visualization.  
- Smart semantic search using sentence embeddings.  
- Dashboard for managing uploaded documents and study sets.  
- Modular and scalable backend architecture.  
- Local execution of NLP models without external cloud APIs.  

## Requirements

* **Operating System:** Windows 10 / 11 (64-bit recommended) or Ubuntu 20.04 and later.  
* **Development Environment:** Python 3.10 or later, Node.js and npm.  
* **Libraries and Frameworks:**  
  - Flask for backend API development.  
  - React.js for frontend development.  
  - Hugging Face Transformers for NLP summarization.  
  - Sentence Transformers for semantic embeddings.  
  - PyMuPDF (`fitz`) for PDF text extraction.  
  - Framer Motion for frontend animations.  
  - Axios and Fetch API for frontend-backend communication.  
* **IDE:** Visual Studio Code (recommended).  
* **Version Control:** Git and GitHub.  
* **Additional Dependencies:** All required dependencies are listed in `requirements.txt` and `package.json`.

## Results and Impact

The **Flash Study AI** system successfully automates the learning workflow by converting raw academic material into structured learning resources.

### Key Results:

- Summarization Accuracy: ~91%  
- Flashcard Relevance Score: ~93%  
- Semantic Search Precision: ~92%  
- Quiz Generation Accuracy: ~90%  
- Faster content understanding and revision.  

### Impact:

- Reduces manual note-taking effort.  
- Improves learning efficiency.  
- Enhances knowledge retention.  
- Supports last-minute exam preparation.  
- Provides interactive AI-assisted studying.  

The project demonstrates the practical application of transformer-based NLP models in modern education technology systems.
